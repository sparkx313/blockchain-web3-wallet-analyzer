# 💼 Web3 Wallet Analyzer

Comprehensive Web3 wallet portfolio analysis tool.

## Features
- Multi-chain portfolio tracking (ETH, Polygon, Arbitrum, BSC)
- DeFi position aggregation across 50+ protocols
- Realized/unrealized P&L calculation
- Tax lot accounting (FIFO/LIFO/HIFO)
- CSV export for tax software (CoinTracker, Koinly compatible)

## Supported Assets
- ERC-20 tokens, LP tokens, receipt tokens
- NFTs with floor price valuation
- Staked positions (Lido stETH, Rocket Pool rETH)
